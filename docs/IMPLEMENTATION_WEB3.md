# Implementation: Web3

Web3 is future scope.

This demo does not connect wallets, sign transactions, use chain-specific signers, or make mainnet claims.

The workshop path can add signer approval later as a separate track:

1. Keep WebAuthn identity separate from wallet addresses.
2. Show the app request before hardware approval.
3. Require explicit user approval for any real external action.
4. Keep demo fixtures and production signing flows visibly separated.
