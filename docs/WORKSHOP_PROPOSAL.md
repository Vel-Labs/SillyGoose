# Workshop Proposal

## Title

From Silly Goose to Serious Approval Boundaries

## Format

A short hands-on workshop that uses the demo to map Ledger-backed approval into normal app workflows.

## Tracks

- Track 1: Web2 auth gate with WebAuthn and Security Key-compatible devices.
- Track 2: sensitive action approval with fresh challenges after login.
- Track 3: Web3 signer approval as future scope, kept separate from WebAuthn identity.

## Outcome

Participants leave with a practical mental model: the app can request, the user can approve, and hardware-backed signing or authentication can become the boundary.
